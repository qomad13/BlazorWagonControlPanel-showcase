# Frontend (Blazor Server UI)

In the full application the UI runs in the same host as the backend (Blazor Server). There are no separate npm dependencies; static files live in `wwwroot`. This repository contains documentation only, so there is nothing to run here.

Example environment values (if the UI configuration needs to be separated):
- `FRONTEND_BASE_URL=http://localhost:5000`
- `API_BASE_URL=http://localhost:5000`
- `DEFAULT_CULTURE=uk`
- `FEATURE_SHOW_DEMO_BUTTONS=true`

See `WHERE_TO_LOOK.md` for the UI entry points of the full application.
