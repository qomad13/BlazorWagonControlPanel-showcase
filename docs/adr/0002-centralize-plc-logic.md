# ADR 0002: Централизовать логику PLC в одном файле
- **Контекст**: операторы/PLC-инженеры меняют правила часто; нужен единый вход.
- **Решение**: хранить всю бизнес-логику PLC в `Plc/PlcLogicEngine.cs`.
- **Альтернативы**: раскидать по сервисам или использовать внешние скрипты.
- **Последствия**: проще ревью/аудит, но файл требует дисциплины и тестов при росте.
