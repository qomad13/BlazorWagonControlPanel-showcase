# ADR 0003: SQLite как хранилище по умолчанию
- **Контекст**: демо и офлайн-развёртывания должны быть простыми.
- **Решение**: использовать SQLite (файл `vagonlab.db`) по умолчанию в EF Core.
- **Альтернативы**: сразу MySQL/PostgreSQL (сложнее поднять демо), InMemory (не сохраняет состояние).
- **Последствия**: легко запускать локально, но масштабирование ограничено; для прод предполагается миграция на полноценную СУБД.
