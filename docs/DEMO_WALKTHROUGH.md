# Обзор функциональности системы

## Основные компоненты UI

### Главная панель (`/`)
- Обзор состояния системы
- Информация о треках (Track 1, Track 2)
- Быстрый доступ к основным функциям

### Страница разработчика (`/developer`)
- **Настройки Modbus**: IP адрес и порт PLC, Slave ID, тест соединения
- **Настройки камер**: 16 камер (8 на трек), RTSP URL, получение снимков
- **Настройки БД**: параметры подключения к MySQL 1C, тест соединения
- **Настройки принтера**: IP адрес и порт сетевого принтера, тест печати

### Страница операций (`/process`)
- **Управление треками**: выбор трека, режим работы (Waiting, Positioning, Sampling), состояние мостов и вагонов
- **Команды**: старт позиционирования, открытие/закрытие люков, старт пробоотбора, печать ярлыков
- **Логи операций**: история действий оператора

### Печать (`/printer`)
- **Печать ярлыков**: выбор трека и вагона, предпросмотр данных, печать одной или нескольких этикеток
- **Логи печати**: история всех операций печати с результатами

## Ключевые функции

### Автоматическая логика PLC
- `PlcLogicEngine` анализирует состояние и автоматически отправляет команды
- Переходы между режимами (Waiting → Positioning → Sampling)
- Обработка фронтов битов от физических кнопок на PLC

### Интеграция с внешними системами
- **Modbus PLC**: опрос регистров состояния, отправка команд
- **MySQL 1C**: чтение справочных данных о вагонах через `MySqlOneCService`
- **RTSP камеры**: получение снимков через OpenCvSharp
- **Сетевой принтер**: печать ярлыков через TCP/IP

### Логирование и мониторинг
- Структурированные логи с контекстом (номер трека, вагона, причина команды)
- Логи операций в БД (`ButtonActions`, `PrinterLogs`)
- Мониторинг соединений с внешними системами
